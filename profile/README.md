# RiiDii.md

An independent Ukrainian workshop for agentic tools, Markdown-native
interfaces, and human-directed AI workflows.

</div>

## What we build

RiiDii.md explores how people and AI agents can think, create, and work
together without losing human direction. We make small, composable tools that
keep agentic work visible, portable, and useful.

## Projects

- [**agentic-livebook**](https://github.com/riidii-md/agentic-livebook) —
  Markdown-native live learning books with agent integration.
- [**mdmaid**](https://github.com/riidii-md/mdmaid) — a Markdown and Mermaid
  renderer for blogs, editors, and developer tools.
- [**mdmaid.desk**](https://github.com/riidii-md/mdmaid.desk) — a persistent
  local presentation workspace for agent-produced Markdown artifacts.
- [**mdmaid.nvim**](https://github.com/riidii-md/mdmaid.nvim) — Neovim
  integration for the Mdmaid renderer.
- [**tatami**](https://github.com/riidii-md/tatami) — a terminal workspace
  manager with native Zellij support.

## Our direction

- Human direction over opaque automation.
- Provider-neutral workflows and tools that compose.
- Local-first operation where ownership and privacy matter.
- Markdown as a durable interface between people, agents, and software.
